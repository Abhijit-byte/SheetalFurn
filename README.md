# Sheetal Furniture

Welcome to the **Sheetal Furniture** project. This directory contains the website and resources for Sheetal Furniture, showcasing high-quality office, institutional, and home furniture items.

## Directory Structure

- [index.html](file:///d:/Projects/sheetal/fur-niture/index.html) - The homepage of the website.
- [style.css](file:///d:/Projects/sheetal/fur-niture/style.css) - The stylesheet containing design tokens and rules.
- [main.js](file:///d:/Projects/sheetal/fur-niture/main.js) - Script for UI interactions and dynamic rendering.
- [product-data.js](file:///d:/Projects/sheetal/fur-niture/product-data.js) - Structured product catalog data.
- [product-detail.html](file:///d:/Projects/sheetal/fur-niture/product-detail.html) - Individual product detail template.
